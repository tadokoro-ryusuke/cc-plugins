# ドキュメント更新

## 目的

コード変更に伴うドキュメントの不整合を解消し、主要ドキュメントを最新の状態に保つ。

## 実行フロー

1. **変更の把握**: `git diff` / `git log` で直近のコード変更を確認する
2. **プロジェクト設定の確認**: `.claude/*.local.md` に追加ツールが指定されていればそれを活用する
3. **更新対象の特定と修正**:
   - README.md: 機能一覧、インストール手順、使用方法、環境変数
   - CLAUDE.md / AGENTS.md: 開発指針との不整合
   - docs/: API 仕様、設計ドキュメント
4. **整合性の確認**: 新機能の記載追加、変更の反映、非推奨・削除機能の記述削除

## 制約

- 既存ドキュメントのスタイル・構成に合わせる
- コードから確認できる事実のみを書く（推測で仕様を書かない）
